# 🎯 Exercícios de Programação Orientada a Objetos (POO) turma ADS II

Este repositório contém uma coleção de exercícios e exemplos práticos desenvolvidos durante a disciplina de **Programação Orientada a Objetos (POO)**. O objetivo principal é consolidar a aplicação dos pilares da orientação a objetos através de problemas práticos.

---

## 📌 Conteúdos Abordados

Os exercícios cobrem os conceitos fundamentais da paradigma de orientação a objetos:

*   **Classes e Objetos:** Instanciação, atributos, métodos e construtores.
*   **Encapsulamento:** Modificadores de acesso, métodos *getters* e *setters* e outros conceitos.
*   **Herança:** Reutilização de código, relação "é um", palavras-chave de extensão.
*   **Polimorfismo:** Sobrescrita (*override*) e sobrecarga (*overload*) de métodos.
*   **Composição:** Associação x Agregação x Composição.
*   **Abstração:** Classes abstratas e interfaces.
